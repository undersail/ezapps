# funphy 关卡元素主题化设计 V1.0

> 2026-08-12 · 目标：每章每关的世界、障碍物、收集品、触发器与关卡主题强相关
> 原则：**"看到什么就知道自己在哪颗星球"** —— 元素即叙事

---

## 1. 设计总览

### 1.1 当前问题

| 问题 | 表现 |
|------|------|
| 障碍物同质化 | `#6b7280`/`#475569` 灰块在 6 章反复出现，岩石/金属/冰面分不清 |
| 颜色误用 | 弹力星 18 个橙色其实是移动墙，非主题色 |
| 收集品单一 | 所有章节都是金色五角星（星尘），无主题区分 |
| 触发器无感 | boost/slow/wind 只是半透明色块，看不出"喷泉/刹车/风" |
| 背景单调 | 只有渐变+星星，无章节地标元素 |

### 1.2 设计原则

1. **元素 = 主题**：障碍物形态（岩石/金属/冰/云/橡胶/能量晶）由星球物理法则决定
2. **收集品 = 星球资源**：每章的"星尘"换成该星球独有的资源（月尘/彩球/气泡/星光/能量块）
3. **颜色体系**：每章一组主题色（背景 + 障碍 + 高光），禁止跨章混用灰色块
4. **形状识别**：一眼识别（岩石=不规则多边形、金属=方板带铆钉、冰=半透明、云=圆润、橡胶=亮色圆角、晶体=菱形发光）

## 3. 障碍物形态设计（kind 体系）

### 3.1 形态定义（SceneRenderer 按 kind 绘制）

```
rock    岩石：不规则 5-6 边多边形，深色底 + 高光棱角（小行星/月岩）
metal   金属：直角方板 + 四角铆钉 + 顶部高光条（空间站/机械）
crystal 晶体：菱形/六边形，半透明 + 边缘发光 + 缓慢脉动（月晶/能量晶）
ice     冰面：半透明方板 + 白色高光斜纹（阻力星）
cloud   云层：圆润云朵形（3 圆叠加），半透明白（大气层）
bounce  橡胶：圆角方块 + 亮色 + 高光弧（弹力游乐场）
orb     星球：大圆 + 表面弧线 + 外圈光环（行星/引力源）
water   水墙：半透明青色 + 流动波纹（水下）
hazard  危险区：保留红色斜纹（通用，跨章可用）
platform 单向平台：保留绿色半透明（通用）
```

### 3.2 数据模型（types.ts）

```ts
// ObstacleDef 新增可选字段
export interface ObstacleDef {
  // ...现有字段
  kind?: 'rock' | 'metal' | 'crystal' | 'ice' | 'cloud' | 'bounce' | 'orb' | 'water'
  // 缺省：按章节主题映射（chapterId → 默认 kind），关卡可覆盖
}
```

**章节默认 kind 映射**（数据里不写 kind 时自动生效）：
| 章节 | 默认 kind | 默认颜色 |
|------|----------|---------|
| 1 惯性星 | metal（墙）/ rock（移动障碍） | #64748b / #8b7a6b |
| 2 重力星 | rock | #94a3b8 |
| 3 弹力星 | bounce | #a78bfa |
| 4 阻力星 | cloud / ice | #e2e8f0 / #67e8f9 |
| 5 引力星 | orb | #fb923c |
| 6 能量星 | crystal / metal | #4ade80 / #d97706 |

### 3.3 收集品主题化

```
CollectibleType 增加视觉映射（逻辑仍是 stardust/checkpoint）：
星尘(默认)   → 金色五角星      （第一章：星尘）
第2章 月尘   → 浅蓝晶粒（六边形）
第3章 彩球   → 粉色圆珠（带高光）
第4章 气泡   → 青色圆泡（半透明+上浮微动）
第5章 星光   → 紫色六芒星
第6章 能量块 → 绿色菱形（发光）
```

### 3.4 触发器主题化

```
boost → 按章变色 + 上升箭头动画（推进器/弹射口/能量喷泉）
slow  → 按章变色 + 阻尼波浪纹（沙地/泥沼/能量耗散）
wind  → 按章变色 + 流动箭头（已有箭头动画，改色）
gravity_well → 画成小星球体（带光环），而非方形色块
```

## 5. 技术实施

### 5.1 分三步落地

| 步骤 | 内容 | 影响 |
|------|------|------|
| **S1 渲染支持** | ObstacleDef.kind + 章节默认映射 + SceneRenderer 按 kind 绘制（8 种形态）+ 收集品/触发器主题化渲染 | 引擎/渲染层，数据零改动即可看到主题化效果（按章自动换肤） |
| **S2 数据标注** | 30 关逐关标注 kind + 主题色（替换灰色块）+ 收集品形状确认 | chapters.ts 数据 |
| **S3 背景地标** | 每章视差背景主题元素（空间站轮廓/环形山/游乐场/大气层/星云/能量网格） | SceneRenderer 背景层（P2 视差背景时一并做） |

### 5.2 兼容性

- `kind` 全部可选，缺省按章节自动映射 → **旧数据零破坏**
- 收集品主题化按章节 id 自动切换（数据不改）
- 现有 hazard/platform 通用样式保留

## 6. 效果预期

- ✅ 进关卡 1 秒内可判断"这是哪颗星球"（背景色 + 障碍形态 + 收集品）
- ✅ 每章障碍物形态统一（岩石就是岩石、金属就是金属）
- ✅ 教学更直觉：弹力星看到橡胶块就知道会弹、阻力星看到云就知道减速
- ✅ 关卡 gimmick 与元素一致（如 3-2 台球 = orb 圆球、5-1 环绕 = 行星视觉化引力井）
