# funphy V2 改版方案详细设计（浮力海洋 → 广袤宇宙）

> 2026-08-12 · 基于用户改版大纲（10 条）细化
> 定位：从 V1"关卡内自由飞行到终点"→ **V2"主题跑酷探险"**：飞船在环境流中躲避迎面障碍、收集资源能量、升级装备、逐章冲出地球进入宇宙

---

## 0. 改版总览

### 0.1 核心转变

| 维度 | V1（现状） | V2（新设计） |
|------|-----------|-------------|
| 玩法 | 关卡内自由飞行到终点 | **跑酷**：障碍物迎面而来，飞船躲避+收集 |
| 章节逻辑 | 物理定律主题（惯性/重力/弹力…） | **环境旅程**（海洋→大陆→天空→轨道→行星→宇宙） |
| 操作 | 单摇杆方向 + 冲刺键 | **双摇杆**：左=方向，右=推力/刹车（键盘等价） |
| 资源 | 星尘（单一货币） | 能量（即时消耗）+ 宝石（升级货币）+ 物理卡（知识） |
| 成长 | 皮肤解锁 | **装备升级**（动力/船体/装饰）影响玩法 |
| 进度 | 30 关独立三星 | **章节解锁链**（每章通关条件 → 下一章）+ 无限宇宙模式 |
| 大厅 | 选关地图 | **剧情大厅**（标题/背景/成就/卡册/船库/双模式入口） |

### 0.2 保留与重写

- **保留**：`PhysicsEngine` 核心（力/碰撞/子步进/软限速）、`SceneRenderer` 主题形态体系（rock/metal/cloud/orb 等 8 种，海洋天空宇宙直接复用）、相机系统、实体类型（弹力垫/传送带/危险区等）、音效引擎
- **重写**：玩法框架（跑酷生成器）、飞船运动模型（自动前进+推杆速度）、能量系统、成长系统、大厅/过场 UI、关卡数据（全部重做）
- **废弃**：V1 的"关卡终点飞行"数据与进度（新老进度不兼容，直接换代）

## 1. 核心玩法循环

### 1.1 探险模式循环

```
大厅 → 选章（剧情推进自动） → 过场卡片（背景介绍，自动消失/可跳过）
     → 跑酷关卡（躲避+收集+能量管理） → 结算（宝石/能量/物理卡）
     → 达标判定（本章通关条件） → 解锁下一章 / 继续小关
```

### 1.2 单关跑酷循环（秒级）

```
飞船自动前进（速度由右推杆控制）
      ↓
左摇杆调整位置躲避迎面障碍（鱼群/山峰/飞机/陨石…）
      ↓
收集宝石（升级货币）· 拾取能量块（+能量）· 飞过太阳能区（持续充能）
      ↓
能量管理：加速耗能 → 能量见底只能滑行（惯性漂移）
      ↓
撞障碍：扣护甲/能量，护甲归零则关卡失败
      ↓
跑完本章路程（进度条）→ 通关结算
```

### 1.3 设计要点

- **一局时长**：60~120 秒（小关）~ 180 秒（章末关）
- **难度曲线**：路程分段（前段教学/中段常规/后段密集），生成密度与速度随进度递增
- **三目标**（对应三资源）：收集 ≥N 宝石 / 剩余能量 ≥M% / 无伤通关（物理卡判定）

## 4. 关卡系统（跑酷生成器）

### 4.1 空间模型（垂直跑酷 ✅ 已确认）

- **飞船自由移动**：不固定在屏幕一侧，可在视口内自由 2D 移动（上下左右）
- **船头朝上**：飞船始终直立（船头向上），像垂直起降飞行器
- **障碍从上生成向下飞**：障碍/资源从视口**顶部**生成，向下飘落/坠落（视觉上"迎面而来"）
- **生成带**：`spawnY = 视口顶缘 - 余量`，实体流出视口底部后回收
- **相机**：飞船自由移动 → 相机跟随飞船（V1 相机系统直接复用），飞船保持在屏幕中下部，障碍从屏幕顶部出现
- **前进感**：飞船向上推进（或自动缓升），障碍下落速度 = 障碍自身流速 + 飞船上升速度（相对运动）

### 4.2 生成器（Spawner）架构

```
Spawner（每关一个，读取关卡配置）
├── 障碍生成器：按 间隔时间轴 生成障碍组（单个/编队/组合）
├── 资源生成器：按 分布模式 生成宝石链（直线/波浪/之字）
├── 能量生成器：能量块（固定点位）+ 太阳能区（持续区域）
└── 难度曲线：生成间隔 × 密度 × 流速 随路程进度递增（三段式）
```

**配置项**：
```ts
interface RunnerLevelConfig {
  length: number              // 路程（单位：世界单位）
  baseFlowSpeed: number       // 基础流速
  segments: SegmentDef[]      // 分段（每段：生成表+密度+流速系数）
  obstacleGroups: GroupDef[]  // 障碍组定义（类型/编队/间隔）
  collectibles: CollectibleDef[]  // 宝石链
  energy: EnergyDef[]         // 能量块点位 + 太阳能区
  physics: PhysicsConfig      // 本章受力
  goal: { gems: number; energyPct: number; noHit: boolean }
}
```

### 4.3 实体类型（V2）

**障碍物**（接触：**护甲制 ✅ 已确认** —— 扣能量 → 扣护甲（初始 3，升级增加）→ 护甲归零失败）：
| 类型 | 行为 | 示例 |
|------|------|------|
| 静态障碍 | 固定位置（垂直模型中=悬停物） | 礁石、卫星 |
| 飘落障碍 | 从顶部生成向下飘（正弦横向摆动） | 水母、热气球、太空垃圾 |
| 俯冲拦截 | 高速斜向下冲 | 飞鱼、飞机、陨石 |
| 旋转体 | 下落同时旋转 | 行星环碎片、风车 |
| 组合阵 | 多障碍编队下落 | 鱼群、鸟群、陨石带 |

**碰撞流程**：撞障碍 → 扣 1 护甲 + 弹开 + 短暂无敌（1s 闪烁）→ 护甲 0 → 关卡失败。护甲为 0 前无失败风险（容错设计，儿童友好）。

**资源**：
| 类型 | 效果 | 形态（复用 kind 渲染） |
|------|------|----------------------|
| 宝石 | +1 升级货币（通关结算累计） | 珍珠/矿石/水晶/钛晶…（按章换肤，沿用主题化体系） |
| 能量块 | +20 能量（立即） | 绿色菱形（能量晶 kind） |
| 太阳能区 | 持续回能（+3/秒） | 金色光柱区（新触发器） |

**危险区**（接触即失败，仅限特定关）：雷暴云、黑洞漩涡、恒星耀斑

### 4.4 主题化生成表（示例：章 1 浮力海洋 关 2）

```
障碍组：
  g1 鱼群：3×上下浮动鱼（正弦，相位差 0.5s）  间隔 8s
  g2 礁石：静态礁 + 珍珠链引导绕行            间隔 12s
  g3 海龟：慢速直线拦截（低密度教学）         间隔 15s
资源：
  珍珠链 ×3（波浪形引导路线）
  能量块 ×2（障碍密集区前补给）
  太阳能区 ×1（海面附近，光柱区）
难度曲线：0-30% 低密度教学 → 30-70% 常规 → 70-100% 密集收尾
```

## 5. 操作与物理

### 5.1 双摇杆操控（触屏）

```
┌─────────────────────────────────┐
│         障碍从顶部生成下落         │
│   ⬇  ⬇  ⬇  ⬇                 │
│                                 │
│           🚀（船头朝上）         │
│         自由 2D 移动             │
├──────────────┬──────────────────┤
│  左摇杆       │   右推杆          │
│  (方向/位移)  │  ▲ 前推=向上推进  │
│  上下左右移动  │  ▼ 后拉=刹车/悬停 │
│  躲避下落障碍  │  松手=滑行        │
└──────────────┴──────────────────┘
```

| 输入 | 效果 |
|------|------|
| 左摇杆（位移） | 飞船自由 2D 移动（躲避下落障碍、走位吃资源），位移速度受本章环境限制 |
| 右推杆（推力） | 行程 0~100% → 向上推力 0~maxThrust（对抗下落/爬升）；后拉 → 反向推力（刹车/下降） |
| 松右杆 | 无推力，惯性滑行（零阻力环境=一直飘，高阻力环境=很快停） |
| 冲刺（保留） | 短时爆发（耗能量加倍），双击右推杆或 ⚡ 键 |

### 5.2 键盘模式（桌面）

| 键 | 功能 |
|----|------|
| W/S 或 ↑/↓ | 上下移动（左摇杆替代） |
| A/D 或 ←/→ | 左右微调 |
| Shift / X | 加速（右推杆前推替代，按住持续加速耗能） |
| 空格 / Z | 刹车（右推杆后拉替代） |
| ESC / P | 暂停 |
| R | 快速重试 |

### 5.3 各章受力模型（引擎参数）

| 章 | thrust | drag | gravity | maxSpeed | 备注 |
|----|--------|------|---------|----------|------|
| 1 海洋 | 0.16 | 0.06（高阻力） | 0.02（浮力近似弱重力） | 0.9 | 慢而稳，刹车灵 |
| 2 大陆 | 0.18 | 0.02 | 0.10 | 1.2 | 重力明显，需持续抵消 |
| 3 天空 | 0.20 | 0.03 | 0.04 | 1.5 | 气流（wind 区）扰动 |
| 4 轨道 | 0.14 | 0（零阻力） | 0 | 1.6 | 惯性难刹——能量管理核心章 |
| 5 行星 | 按行星 | 0.01 | 0.03~0.18 | 1.4~1.7 | 每关行星重力不同 |
| 6 宇宙 | 0.18 | 0 | 0 | 1.8 | 黑洞区局部引力井 |

> 数值沿用 V1 校准过的帧单位体系（thrust 0.15~0.2 档），手感基线已验证。

## 6. 能量系统

### 6.1 核心规则

```
能量池：0 ~ 100
消耗：推进时 = 推力比例 × 消耗率（默认 2.5/秒 @ 满推力）
      冲刺 = 额外 +15/次
规则：能量 > 0 才能推进；能量 = 0 → 只能滑行（保留惯性，无法加速/刹车）
获取：太阳能区  +3/秒（持续）
      能量块    +20（拾取即时）
      通关结算  +10 保底（鼓励完成）
```

### 6.2 平衡设计（能量策略循环）

- **加速是奢侈的**：满推力 40 秒耗空能量 → 玩家必须规划"冲刺段/滑行段"
- **太阳能区 = 经济中心**：穿越光柱回能，但光柱往往布置在障碍密集区（收益与风险并存）
- **各章能量压力**：海洋关宽松（教学）→ 轨道关严苛（惯性+耗能双压力）→ 宇宙关极限
- HUD：能量条（顶部，渐变绿→黄→红），低能量闪烁警告音

### 6.3 与速度挑战的关系（通关条件）

- 第一/二/三宇宙速度 = 关卡内 **冲速挑战**：在指定能量补给充足的关卡，保持满推力冲刺，速度表达到阈值（如 1.5/1.7/2.0 单位/帧）并维持 3 秒
- 设计保证：能量块布局恰好支撑"冲刺-回能-冲刺"节奏（关卡编辑器硬性规则）

## 7. 成长系统

### 7.1 货币与资源

| 资源 | 获取 | 用途 |
|------|------|------|
| 能量 | 关卡内即时 | 推进消耗（不跨关累计） |
| 宝石 | 关卡收集（结算累计） | 升级装备 |
| 物理卡 | 章节通关 | 知识收集（卡册） |

### 7.2 装备系统（飞船库）

| 槽位 | 装备 | 升级效果（每级） | 成本（宝石） |
|------|------|----------------|-------------|
| 动力 | 推进器 | +8% 推力 / -6% 能耗 | 10/25/50/100 |
| 船体 | 护甲 | +1 撞击承受（初始 3）| 15/40/80 |
| 船体 | 能量仓 | +10 能量上限 | 20/50 |
| 装饰 | 外观/尾焰 | 纯外观（延续 V1 皮肤体系）| 5~200 |

- 装备等级影响 `PhysicsConfig`（thrust/能耗率）与 `GameRuntime`（护甲值）
- **章节通关条件绑定装备等级**（§8），驱动"刷宝石→升级→通关"循环

### 7.3 物理卡（知识系统）

- 沿用 V1 卡册框架，主题改为"环境物理"：浮力/重力/阻力/惯性/万有引力/能量守恒
- 30 张（每章 5 张），达成关卡目标（无伤/满能量/全收集）解锁
- 卡面：直觉名称 + 现象描述 + 正式概念 + 生活实例（V1 体系直接复用）

## 8. 通关与解锁链

### 8.1 章节解锁流程

```

第6章 无限模式：无通关点，排行榜式里程挑战（本地最佳记录）

│  🚀 飞飞历险记（标题）               │
│  故事背景（一行简介 + 展开按钮）      │
│  ┌───────────┬──────────────────┐  │
│  │ 进度与成就  │  飞船库（装备/外观）│  │
│  │ · 当前章节  │  物理卡册入口      │  │
│  │ · 宝石/能量 │                   │  │
│  └───────────┴──────────────────┘  │
│  [🚀 开始探险]   [🔄 故地重游]       │
└────────────────────────────────────┘
```

### 9.2 探险模式（故事模式）

- 连续运行：关卡间自动衔接，无地图选择
- **关卡开场卡片**：背景介绍（右上角卡片，3 秒自动消失 / 点击跳过），不遮挡游戏主画面
- **小关悬浮提示**：游戏内顶部悬浮文字（如"← 躲避鱼群"），短暂显示自动消失，不遮挡
- 结算界面：宝石/能量/物理卡 + 章节进度 + 通关条件达成提示

### 9.3 重游模式（自由探索）

- 关卡卡片网格（章节分组，锁定/解锁/完成状态）
- 点击进入，玩法同探险模式（无过场卡片）

## 10. 飞船重新设计（V2 新造型）

### 10.1 设计目标

> V1 飞船是"横向小飞机"（船头朝左/右）。V2 改为**垂直起降全能飞船**：船头朝上，造型更酷、更有科技感，且随装备升级有外观成长。

### 10.2 造型规格（Canvas 绘制，无图片资源）

```
        ▲ 船头（箭头尖，金属高光）
      ◇ 驾驶舱（上部，发光圆窗+表情眼睛）
     ╱│╲ 机翼（X 形四翼，水平展开）
    ╱ │ ╲
   │  ●  │  能量环（机身中部光环，随能量/冲刺变化）
    ╲ │ ╱
     ╲│╱
      ███   机身（垂直流线箭头体）
      ███
      [▼]   引擎喷口（底部双喷口）
      ~~~~  尾焰（向下喷射 = 向上推进）
```

| 部件 | 设计 |
|------|------|
| 机身 | 垂直拉长的箭头/泪滴形（宽 5 ~ 高 11 单位），双色分层（主色+深色边缘） |
| 船头 | 尖头 + 顶部高光条，流线感 |
| 驾驶舱 | 机身上部圆形舱窗（发光边框），表情眼睛画在舱窗内（保留 V1 表情系统：正常/推进/受击/胜利） |
| 机翼 | X 形四翼（水平双翼 + 倾斜双翼），翼尖小灯（推进时亮） |
| 能量环 | 机身中部椭圆光环，常态半透明蓝；冲刺/高能时亮金色并旋转 |
| 引擎 | 底部双喷口，尾焰向下喷射（火焰/离子/冰晶等按皮肤），冲刺时尾焰加长加亮 |
| 护甲反馈 | 受击时能量环碎裂闪烁 + 机身抖动（护甲制视觉化） |

### 10.3 皮肤与外观成长

- 沿用 V1 皮肤体系（bodyColor/flameColor/flameShape），**新增**：
  - 翼型差异（X 翼/直翼/三角翼）按皮肤
  - 能量环颜色随皮肤
- **装备升级外观成长**：动力 Lv2+ 引擎喷口变双环；护甲 Lv2+ 机身出现装甲条；能量仓 Lv2+ 能量环更亮 —— 升级可见（激励循环）

### 10.4 与物理的关系

- 造型纯视觉（碰撞体仍为圆形 `radius`，不随造型变化 —— 公平性）
- 船头始终朝上（不做朝向旋转；V1 的"速度方向旋转"移除）



## 11. 技术架构

### 11.1 引擎与渲染改造

| 模块 | 改造 |
|------|------|
| `PhysicsEngine` | 保持核心；新增"生成器流"支持（实体从 spawnX 注入/回收） |
| `RunnerSpawner`（新） | 关卡生成器：按配置产出障碍组/资源/能量区 |
| `SceneRenderer` | 复用主题形态；新增太阳能区（光柱）、宝石链（沿用主题化收集品）、冲速 HUD |
| 相机 | 固定视口（飞船 x 固定），世界滚动由生成器模拟 —— 相机系统简化 |
| `useInput` | 双摇杆：左摇杆位移 + 右推杆推力/刹车 |
| 能量系统（新） | `useEnergy`：池、消耗/获取、HUD 联动 |
| 成长系统（新） | `useUpgrades`：宝石、装备等级 → 物理参数注入 |
| 进度 | `GameProgress` V2 schema（章节解锁/宝石/装备/物理卡/里程记录） |

### 11.2 数据结构（V2 schema）

```ts
interface RunnerLevelDef {
  id: string; chapter: number; order: number
  name: string
  length: number
  physics: PhysicsConfig            // 本章受力（装备等级注入后生效）
  segments: RunnerSegment[]          // 生成分段
  goal: { gems: number; energyPct: number; noHit: boolean }
  bgGradient: [string, string]
}

interface ChapterDefV2 {
  id: number; title: string; emoji: string
  introCard: string                  // 过场卡片文案
  physics: PhysicsConfig
  unlock: { gems: number; upgrade: string; speed?: number }  // 通关条件
  levels: RunnerLevelDef[]
}

interface GameProgressV2 {
  version: 2
  chapter: number                    // 当前章节
  gems: number
  upgrades: Record<string, number>   // 装备等级
  cards: string[]                    // 物理卡
  skins: string[]
  bestDistances: Record<string, number>  // 宇宙关里程记录
}
```

### 11.3 与 V1 代码的衔接

- V1 关卡数据（chapters.ts）**整体替换**为 V2 章节数据（新文件 `data/runner/`）
- V1 进度 key `funphy_progress` 作废，新 key `funphy_v2_progress`（版本隔离，避免老存档污染）
- 物理引擎、渲染器、音效、实体类型：直接复用（已验证稳定的部分）
- 组件级：LevelSelect/卡册/皮肤选择可改造复用；GameCanvas 重写为跑酷画布

## 13. 风险与对策

| 风险 | 对策 |
|------|------|
| 跑酷手感难调（速度/密度/能量三变量） | 参数表驱动 + 分段难度曲线；每章先用教学关验证手感 |
| 内容量巨大（30 关生成配置） | 生成配置模板化（章节内关卡由模板+参数派生），先做 1 章验证 |
| 能量系统可能"要么太松要么太卡" | 消耗率/获取率作为全局可调参数，试玩校准（±20% 步进） |
| 双摇杆学习成本（儿童用户） | 键盘等效 + 第一章教学关悬浮提示引导；海洋关低压力试错 |
| V1 资产浪费 | 引擎/渲染/音效/实体全部复用；皮肤与卡册框架保留 |
