# 飞飞历险记 V2 打磨优化设计方案
> 资源素材 · 关卡难度 · 操控策略 三线优化（2026-08-13）

## 一、资源视觉升级（块图标标识）

### 1.1 宝石块（钻石形态 + 💎 标识）
- **现状**：白色圆珠（珍珠），按章换色
- **改版**：菱形宝石造型（程序化绘制）
  - 菱形主体（按章配色：海洋金 / 大陆蓝 / 天空粉 / 轨道青 / 行星紫 / 宇宙绿）
  - 中心白色💎切面高光（两条交叉亮线）
  - 小尺寸时只画菱形 + 高光点（保证辨识度）
- 分值 3+ 的中大宝石：加外圈星芒闪烁（旋转 4 芒星），一眼看出"值钱"

### 1.2 能量块（⚡ 标识）
- **现状**：绿色方块
- **改版**：绿色圆角方块 + 白色 ⚡ 闪电图标（Canvas 折线绘制，中心偏上）
  - 小能量块：方块 + 小闪电
  - 大能量块：方块 + 大闪电 + 外圈脉冲光环（呼吸效果）

### 1.3 绘制原则
- 全部 Canvas 程序化（无图片资源）
- 图标颜色白/亮色，与块底色强对比（深色背景可辨）

## 三、高处资源 + 消失倒计时机制（冒险奖励）

### 3.1 设计意图
制造"**冒险 vs 安全**"抉择：高处（视口上部 y=8~22）资源价值高，但通常位于障碍密集区上方，飞上去拿要冒撞障碍/耗能的风险。倒计时让抉择有紧迫感。

### 3.2 生成规则
- 大宝石/大能量块 **50% 概率**生成在视口上部（y=8~22），50% 常规路径
- 生成时标记 `expiresIn`（秒）：大宝石 10s / 大能量块 8s
- 生成点下方通常布置 1-2 个障碍（"守宝"设计）

### 3.3 消失表现
- 剩余 3 秒：块**闪烁**（0.3s 间隔 alpha 0.3↔1）
- 剩余 3 秒同时显示**倒计时数字**（块上方小数字 3/2/1）
- 到期：播放"消失"微效（缩小 + 淡出），不产生任何收益
- 音效：倒计时开始"滴"一声（可选，V2-7.3）

### 3.4 数据模型
```ts
interface SpawnDef {
  // ...现有字段
  size?: 's' | 'm' | 'l'        // 大小档
  expiresIn?: number            // 秒，>0 时高处生成+倒计时
}
```

## 四、关卡难度分级体系

### 4.1 难度维度（每关 5 项配置）
| 维度 | 含义 | 实现 |
|---|---|---|
| 障碍密度 | 每 100 里程 spawn 数 | spawns 数量/长度 |
| 类型混合 | falling/dive/swarm 比例 | 数据分布 |
| 下降速度 | fallSpeed 基准 | baseFlow + fallSpeed |
| 资源丰度 | 宝石/能量块数量 | spawns 配比 |
| 能量压力 | 能耗率 + 补给间隔 | energyDrain + 能量块间隔 |

### 4.2 六档难度标尺
| 档 | 名称 | 特征 | 关卡示例 |
|---|---|---|---|
| T1 | 教学 | 稀疏障碍、密集资源、慢速 | 1-1 2-1 3-1 |
| T2 | 轻松 | 基础躲避、资源充足 | 1-2 2-3 5-3 |
| T3 | 标准 | 编队+俯冲入门 | 1-3 2-2 3-2 4-2 |
| T4 | 挑战 | 高密度+能量压力 | 1-4 2-4 3-4 4-4 |
| T5 | 刺激 | 全类型混合+急流 | 4-3 5-2 5-4 |
| T6 | 极限 | 章末综合/无限模式 | 1-5 2-5 3-5 4-5 5-5 6-1 |

### 4.3 参数模板（示例对照）
| 参数 | T1 | T3 | T5 |
|---|---|---|---|
| 障碍/100里程 | 1.2 | 2.2 | 3.5 |
| dive 占比 | 0% | 30% | 50% |
| fallSpeed 基准 | 0.4 | 0.6 | 0.85 |
| 宝石/关 | 14 | 10 | 8（但高分值多）|
| 能量块间隔 | 120 里程 | 220 | 300 |
| energyDrain | 2.0 | 2.3 | 2.6 |

### 4.4 实现
- 数据文件加 `difficulty: 'T1'..'T6'` 标注 + 生成器按档位自动补参
- 现有 26 关重新标注档位 + 微调 spawns（保留手写特色，自动参数兜底）

## 五、操控升级体系（装备 → 手感提升）

### 5.1 装备等级 → 操控参数映射
| 装备 | Lv1 | Lv2 | Lv3 | Lv4 |
|---|---|---|---|---|
| ⚙️ 引擎 | 加速响应 0.18→0.22 | →0.26 | →0.30（更跟手） | 0.34 |
| | 推力 1.08× | 1.16× | 1.24× | 1.32× |
| | 尾焰长度 1.12× | 1.24× | 1.36× | 1.48×（金色） |
| 🛡️ 护甲 | 无敌帧 55 | 45 | 35 | 25（受击硬直缩短）|
| | 船体星徽 | 银星→金星 | 金星+光环 | 光环脉动 |
| 🔋 能量仓 | 上限 +10 | +20 | +30 | +40 |
| | 能量环亮 1.15× | 1.30× | 1.45× | 1.60× |

### 5.2 "跟手性"具体实现
- **加速响应 lerp**：`ship.vx += (targetVx - ship.vx) * lerp`，引擎升级 → lerp 0.18→0.34（摇杆松手更快停下、转向更干脆）
- 垂直同理（油门响应）
- 冲刺冷却随引擎缩短：90 帧 → 75 → 60（Lv4 可连冲）
- 护甲升级 → 受击弹开距离减小（0.9×）+ 无敌时间缩短（技术好的玩家吃亏？不 —— 无敌缩短是"高风险高回报"：甲多但挨打后反应窗口短）

### 5.3 飞船样式随升级
- 已有：星徽/尾焰/能量环
- 新增：Lv2+ 引擎尾焰**双色渐变**（蓝→金）；Lv3+ 船体边缘发光；Lv4 尾焰粒子更密

## 六、实施顺序建议
1. **§一/§二** 资源视觉 + 大小分级（渲染层，独立可验证）
2. **§三** 高处资源 + 倒计时（机制层，与 1 联动）
3. **§四** 关卡难度分档（数据层，26 关标注 + 调参）
4. **§五** 操控升级（手感层，参数注入）
5. 全量试玩校准（重点：T5/T6 刺激度、高处资源回报率）

## 七、验证方式
- 每步浏览器实测：图标可辨（像素/截图）、倒计时消失计时、升级前后 lerp 差值（Node 模拟）
- 难度梯度：同一操作模式通关时间/失败率对比
