# 🚀 飞飞历险记 · 游戏手册

> 驾驶全能飞船，从地球海洋出发，穿越大陆与天空、失重轨道、行星世界，最终冲向浩瀚宇宙！

---

## 一、基本玩法

飞飞驾驶飞船在垂直航道中飞行：**障碍物从顶部不断下落**，飞船自由移动躲避障碍、收集资源，向前推进里程。

- **推进**：持续前进，里程攒满即通关
- **护甲**：初始 3 点，撞障碍扣 1 点，归零则挑战失败
- **能量**：推进消耗能量，能量耗尽只能滑行（无法加速）

## 二、操作说明

### 📱 触屏（单摇杆）
| 操作 | 效果 |
|---|---|
| 摇杆 **左右** | 飞船左右移动 |
| 摇杆 **上推** | 加速（上升 + 流速加快） |
| 摇杆 **下拉** | 刹车（下降 + 流速减慢） |
| **⚡ 键**（右下） | 冲刺：0.3 秒全油门爆发（耗 8 能量） |

### ⌨️ 键盘
| 按键 | 效果 |
|---|---|
| ← → | 左右移动 |
| ↑ | 加速 |
| ↓ | 刹车 |
| Shift / X | 冲刺 |
| ESC / P | 暂停 |
| R | 快速重试 |

## 四、障碍物

| 障碍 | 说明 |
|---|---|
| 普通障碍 | 撞上扣 1 护甲 |
| 🔴 **红边大障碍** | 高危警告！撞上**击退更远**（重击） |
| ❓ **问号盲盒** | 撞了**不扣甲**，随机开奖： |

**盲盒奖池**：
- 🎁 宝石 +6（20%）
- ⚡ 能量 +35%（20%）
- 🛡️ 护甲 +1（15%）
- ⚡ 能量 -15%（15%）
- 💥 扣 1 甲（30%）

障碍下落有快有慢（±25% 波动），俯冲型障碍速度极快，注意提前预判。

## 五、六大章节

| 章节 | 环境 | 物理特色 | 主题元素 |
|---|---|---|---|
| 🌊 浮力海洋 | 水下 | 微重力（0.01） | 鱼群/气泡/鱼形障碍 |
| ⛰️ 重力大陆 | 陆地 | **强重力**（0.08-0.11）需持续对抗 | 山峦/松树 |
| ☁️ 自由天空 | 高空 | 轻重力（0.04） | 白云/飞鸟/鸟形障碍 |
| 🛰️ 失重轨道 | 太空 | **零重力零阻力**（惯性滑行） | 星空/卫星 |
| 🪐 行星世界 | 多行星 | **每关重力不同**（0.06-0.14） | 行星远景/光环 |
| 🌌 冲向宇宙 | 星际 | 零重力高速 | 星云/繁星 |

**第 6 章 5 关**：☄️ 彗星航道 → 💫 白矮星引力阱 → 🕳️ 黑洞边缘 → 🌠 冲出银河系（终极挑战）→ 🏁 **星际漫游（无限模式·终章）**

**难度分级**（T1 教学 → T6 极限）：越靠后的章节障碍越密集、下落越快、大块和盲盒越多。

## 六、成长系统

### 🛠 飞船库（大厅 / 游戏中 🛠 键随时升级）
| 装备 | 效果/级 | 成本 💎 |
|---|---|---|
| ⚙️ 动力引擎 | 推力 +8%、能耗 -6%、**操控更跟手**、冲刺冷却缩短 | 10/25/50/100 |
| 🛡️ 船体护甲 | 护甲 +1、受击硬直缩短 | 15/40/80/160 |
| 🔋 能量仓 | 能量上限 +10 | 20/50/100 |

**升级可见外观**：护甲→机尾星徽（银/金/光环）、引擎→尾焰加长、能量仓→能量环更亮；总等级 6+ → **金色旗舰船体** 🏆

### 📚 物理卡册（30 张）
每通关一关解锁一张物理卡（直觉名 + 学名 + 生活例子），首次获得自动弹出 —— 玩着玩着就把物理知识学了！

## 七、游戏模式

### 🚀 探险模式
从最新进度连续闯关，通关解锁下一关，章末关通关解锁下一章。**开始探险按钮显示当前进度**，随时续玩。

### 🔄 重游模式
已解锁关卡自由重玩刷宝石（通关状态 ✅、可玩 ▶、锁定 🔒）。

### 🌌 无限模式（第 6 章终章）
6-5 星际漫游：没有通关点，一直跑！红矮星/白矮星/黑洞三区循环，**跑到 800 里程即算通关**（解锁下一成就），挑战**最佳里程** 🏅。

## 八、新手小贴士

1. **别一直按加速**：全油门时障碍下落飞快，学会"短按油门 + 滑行"的节奏
2. **太阳区是补给站**：能量紧张时躲进金色光柱回满
3. **大块值得冒险**：6 分宝石 = 6 个普通宝石，限时但慢速下落，规划路线去拿
4. **盲盒是双刃剑**：55% 赚 45% 亏，护甲不满时慎撞
5. **优先升引擎**：操控跟手性提升最明显，全游戏受益
6. **刷宝石路线**：重游模式选 1-1（教学关，宝石多障碍少）快速攒钱
7. **惯性关卡（第 4 章）**：推一下刹不住，提前规划减速，别横冲直撞
