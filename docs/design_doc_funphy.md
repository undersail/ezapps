# 飞飞历险记（Funphy Adventure）游戏设计方案 V0.2

> 2026-08-12 · 基于 funmath V1 试玩反馈重新设计

---

## 1. 设计理念

### 1.1 核心问题

funmath V1 试玩反馈："不好玩没意思"。根因：数学是任务，不是玩法。小朋友觉得自己在做题，不是在玩。

### 1.2 核心原则

**物理是玩法本身，不是考试内容。** 飞飞（小航天飞机）在宇宙中飞行，物理规律是飞飞行动的法则。小朋友操控飞飞的过程中，直觉地感受物理规律，而不是被"教"物理。

### 1.3 教育理念：先玩后悟

- 关卡设计只突出一个物理概念，让小朋友通过玩来"感受到"
- 不在关卡前弹出"今天我们学习 XXX"
- 通关后解锁"物理卡"：你刚才用到的就是"惯性"
- 失败后给操作提示："试试提前减速？"，而不是物理课

### 1.4 与 funmath 的对比

| 维度 | funmath（失败） | funphy（新设计） |
|------|-----------------|-------------------|
| 学科与玩法的关系 | 数学是"考题"，做题是"拆墙" | 物理是"动作"，操控飞飞就是物理本身 |
| 交互多样性 | 永远是选ABCD | 飞行、碰撞、反弹、重力……每关有不同物理机制 |
| 即时反馈 | 对/错 + 下一题 | 飞飞飞起来、撞墙、被弹开——感受即反馈 |
| 叙事可能 | 靠文字描述"曼曼进入森林" | 飞飞穿过峡谷、躲避陨石、降落在星球——场景即叙事 |

| 项 | 定义 |
|----|------|
| **一句话** | 操控小航天飞机飞飞，在不同星球用物理法则闯关 |

## 3. 飞飞形象

小航天飞机，圆润可爱风格。特征：

- **圆润可爱**：不是真实航天飞机那种尖头，更像卡通小飞机
- **有表情**：正常😊、加速😤、撞墙😵、通关🎉
- **有尾焰**：推进时显示火焰，方向跟随推力方向
- **有护盾**：受到撞击时闪烁

SVG 绘制，纯前端 Canvas 渲染，不需要图片资源。

## 4. 操控方式

### 4.1 双模式：触屏 + 键盘

#### 触屏（主要）

```
┌─────────────────────────┐
│                         │
│     游戏场景区域         │
│                         │
│    [飞飞在这里飞]        │
│                         │
│                         │
├─────────────────────────┤
│  ◀  ▲  ▼  ▶   [暂停]   │
│  左  上  下  右          │
└─────────────────────────┘
```

- 底部虚拟方向键（D-Pad），拇指操作
- 按住 = 持续施力，松开 = 停止施力（但飞飞因惯性继续飞）
- 点按场景区域 = 无操作（防止误触）

#### 键盘（辅助/桌面）

- WASD 或方向键

## 5. 世界观

> 飞飞是一艘小航天飞机，在宇宙中旅行。每个星球有不同的物理法则，飞飞需要适应这些法则才能完成任务。
>
> 飞飞不是"学物理"，而是"用物理生存"。

为什么选宇宙：
- 不同星球 = 不同物理参数，天然适合关卡设计
- 太空 = 零阻力/微重力，天然适合物理教学
- 星球 = 有重力/大气/地形，天然适合对比
- 小朋友对太空天然好奇

---

## 6. 核心循环

```
选择星球 → 降落到场景 → 用物理操控飞飞完成任务 → 获得星尘 → 解锁新星球
```

和 funmath 的关键区别：
- **funmath**：看题→选答案→对错→下一题（被动）
- **funphy**：看场景→操控飞飞→感受物理→调整策略→完成挑战（主动）

---

## 7. 章节与关卡设计

**6 章 × 4 普通关 + 1 Boss = 30 关**

| 章 | 星球 | 物理主题 | 章节核心概念 |
|----|------|---------|-------------|
| 1 | 惯性星 | 牛顿第一定律 | 没有外力时，物体保持匀速直线运动或静止 |
| 2 | 重力星 | 重力与自由落体 | 重力使物体加速下落，不同星球重力不同 |
| 3 | 弹力星 | 弹性碰撞与动量 | 碰撞时动量守恒，弹性碰撞会反弹 |
| 4 | 阻力星 | 摩擦力与空气阻力 | 阻力与速度方向相反，使物体减速 |
| 5 | 引力星 | 万有引力与轨道 | 引力与距离平方反比，可以形成轨道 |
| 6 | 能量星 | 动能与势能转换 | 能量守恒，动能势能互相转换 |

### 7.1 第一章：惯性星 · 详细设计

**星球设定**：无重力、无阻力的太空空间站外围。飞飞在这里没有"刹车"，推一下就永远飞。

#### 1-1 太空漫步 ⭐
- **场景**：开阔空间，3 个收集品（星尘），终点标记
- **任务**：收集所有星尘并到达终点
- **物理参数**：无重力、无阻力、推力适中
- **通关条件**：到达终点
- **三星条件**：60秒内 / 40秒内 / 25秒内
- **玩家感受**：推一下飞飞就停不下来，第一次体验"惯性"
- **失败模式**：飞出边界（边界反弹，不惩罚但浪费时间）
- **通关物理卡**：推一下停不下来（牛顿第一定律）

#### 1-2 躲避小行星 ⭐⭐
- **场景**：小行星带，6-8 个小行星缓慢移动
- **任务**：穿越小行星带到达终点
- **物理参数**：无重力、无阻力、推力更大
- **通关条件**：到达终点且碰撞 ≤ 3 次
- **三星条件**：碰撞 ≤ 2 / ≤ 1 / 0 次
- **玩家感受**：不能急转弯，必须提前规划——惯性让你不能随心所欲
- **关键设计**：小行星间距需要提前计算，不能临时闪避
- **通关物理卡**：大块头更倔（惯性大小与质量）

#### 1-3 精准对接 ⭐⭐
- **场景**：空间站对接舱口，有速度限制区
- **任务**：以低速（< 1.0）触碰对接点
- **物理参数**：无重力、无阻力
- **通关条件**：对接成功（速度达标）
- **三星条件**：速度 < 0.8 / < 0.5 / < 0.3
- **玩家感受**：快了撞坏，慢了到不了——速度控制是惯性的核心挑战
- **视觉提示**：对接舱口有速度指示灯（绿=安全，黄=快了，红=太快）
- **通关物理卡**：两个力拉平手（二力平衡）

#### 1-4 星尘收集赛 ⭐⭐⭐
- **场景**：12 颗星尘散布，有移动障碍
- **任务**：30 秒内收集 ≥ 8 颗星尘
- **物理参数**：无重力、无阻力
- **通关条件**：收集 ≥ 8 颗
- **三星条件**：≥ 8 / ≥ 10 / 全部收集
- **玩家感受**：利用惯性滑行省燃料，规划路线——惯性是朋友
- **关键设计**：直线穿越多颗星尘的路线比折返路线更高效
- **通关物理卡**：刹车的"飞来横祸"（惯性现象）

#### 1-5 Boss：惯性迷宫 ⭐⭐⭐⭐
- **场景**：复杂迷宫，有移动墙壁和窄通道，3 个检查点
- **任务**：通过所有检查点到达终点
- **物理参数**：无重力、无阻力、推力可变（有加速区）
- **通关条件**：到达终点
- **三星条件**：120秒内 / 90秒内 / 60秒内
- **特殊机制**：
  - **加速区**：经过时自动加速（黄色区域）
  - **减速区**：经过时自动减速（蓝色区域）
  - **移动墙壁**：定时开合，必须卡时机通过
- **玩家感受**：综合运用惯性知识，学会"借力"和"预判"
- **通关物理卡**（稀有金色）：你推我，我也推你（牛顿第三定律）

### 7.2 第二章：重力星 · 详细设计

**星球设定**：有重力的小行星，飞飞会被向下拉。像月球一样——重力小但存在。

#### 2-1 登月 ⭐
- **场景**：从高处降落，需要着陆在平台
- **任务**：安全着陆（速度 < 1.5）
- **物理参数**：低重力（0.15），无阻力
- **通关条件**：着陆在平台上且速度达标
- **三星条件**：速度 < 1.2 / < 0.8 / < 0.5
- **玩家感受**：飞飞会自动下落，需要向上推来对抗重力——重力是什么
- **通关物理卡**：地球在拽你（重力）

#### 2-2 跳跃峡谷 ⭐⭐
- **场景**：多个平台，需要跳过去
- **任务**：跳过所有平台到达终点
- **物理参数**：低重力（0.15），无阻力
- **通关条件**：到达终点
- **三星条件**：不掉落 ≤ 2 / ≤ 1 / 0 次
- **玩家感受**：抛物线轨迹——重力 + 水平速度 = 抛物线
- **通关物理卡**：同时落地（自由落体运动）

#### 2-3 多重重力 ⭐⭐⭐
- **场景**：场景中有多个重力源（小星球），飞飞受合力影响
- **任务**：从起点到达终点
- **物理参数**：多个重力源，合力决定飞飞运动
- **通关条件**：到达终点
- **三星条件**：60秒内 / 40秒内 / 25秒内
- **玩家感受**：被不同方向拉扯——重力可以叠加
- **通关物理卡**：越坠越快（重力加速度）

#### 2-4 自由落体 ⭐⭐⭐
- **场景**：垂直矿井，需要下落并躲开障碍
- **任务**：下落到底部，收集星尘
- **物理参数**：强重力（0.3），无水平控制，只有左右微调
- **通关条件**：到达底部且收集 ≥ 6 星尘
- **三星条件**：≥ 6 / ≥ 8 / 全部收集
- **玩家感受**：加速下落越来越快——自由落体加速
- **通关物理卡**：全部重量假装在一个点（重心）

#### 2-5 Boss：重力切换 ⭐⭐⭐⭐
- **场景**：场景中重力方向会周期性切换（上↓下↑左→右←）
- **任务**：在重力切换中到达终点
- **物理参数**：重力方向周期切换，每 5 秒变一次
- **特殊机制**：重力切换有 1 秒预警（箭头闪烁）
- **通关条件**：到达终点
- **三星条件**：60秒内 / 45秒内 / 30秒内
- **通关物理卡**（稀有金色）：一会儿变重一会儿变轻（超重与失重）

### 7.3 第三章：弹力星 · 详细设计

**星球设定**：充满弹性物体的星球。飞飞撞墙、撞球都会反弹，反弹力度取决于碰撞方式。

#### 3-1 弹力墙 ⭐
- **场景**：封闭空间，墙壁弹性系数很高
- **任务**：利用墙壁反弹到达目标
- **物理参数**：无重力，墙壁弹性系数 0.9
- **通关条件**：到达目标
- **三星条件**：60秒内 / 40秒内 / 25秒内
- **玩家感受**：撞墙会弹回来——弹性碰撞
- **通关物理卡**：撞完换速度（弹性碰撞）

#### 3-2 台球飞飞 ⭐⭐
- **场景**：有多个彩色球体，飞飞撞击后球会移动
- **任务**：用飞飞撞特定颜色的球到目标区域
- **物理参数**：无重力，动量守恒
- **通关条件**：所有目标球到达指定区域
- **三星条件**：120秒内 / 90秒内 / 60秒内
- **玩家感受**：撞球后自己会减速——动量守恒
- **通关物理卡**：撞一个弹一串（动量守恒的连锁碰撞）

#### 3-3 连锁反应 ⭐⭐⭐
- **场景**：多个球排列，需要一球撞多球
- **任务**：触发连锁碰撞，让所有目标球到达指定位置
- **物理参数**：无重力，不同球质量不同
- **通关条件**：所有目标球到位
- **三星条件**：90秒内 / 60秒内 / 40秒内
- **玩家感受**：轻球撞重球弹开很远，重球撞轻球几乎不停——质量与动量
- **通关物理卡**：撞完粘一起（完全非弹性碰撞）

#### 3-4 弹力跳板 ⭐⭐⭐
- **场景**：有弹力跳板，需要利用跳板弹射到高处
- **任务**：通过弹力跳板到达高处平台
- **物理参数**：有重力（0.15）+ 弹力跳板
- **通关条件**：到达顶部平台
- **三星条件**：碰撞 ≤ 5 / ≤ 3 / ≤ 1 次
- **玩家感受**：下落越快弹得越高——弹性势能
- **通关物理卡**：撞得狠，接得柔（动量定理）

#### 3-5 Boss：弹力迷宫 ⭐⭐⭐⭐
- **场景**：复杂迷宫，只能通过精确反弹通过窄通道
- **任务**：利用反弹到达所有检查点
- **物理参数**：无重力，不同墙壁弹性不同，有固定弹力球
- **特殊机制**：计算反弹角度，利用弹力球改变方向
- **通关条件**：到达终点
- **三星条件**：90秒内 / 60秒内 / 40秒内
- **通关物理卡**（稀有金色）：轻的撞重的，自己被弹回（动量守恒中质量与速度）

### 7.4 第四章：阻力星 · 详细设计

**星球设定**：有大气层的星球，飞飞在空中飞行时受到空气阻力。速度越快阻力越大，下落速度有上限。

#### 4-1 大气层飞行 ⭐
- **场景**：有大气层的开阔空间，需要飞到终点
- **任务**：从起点飞到终点
- **物理参数**：低重力（0.1），有空气阻力（阻力系数 0.02）
- **通关条件**：到达终点
- **三星条件**：60秒内 / 40秒内 / 25秒内
- **玩家感受**：推了不会一直加速，速度会稳定下来——阻力与推力平衡
- **通关物理卡**：地面拖后腿（滑动摩擦力）

#### 4-2 水中穿行 ⭐⭐
- **场景**：水下空间，阻力极大
- **任务**：在水下穿行到达终点
- **物理参数**：低重力（0.1），高阻力（阻力系数 0.08）
- **通关条件**：到达终点
- **三星条件**：60秒内 / 45秒内 / 30秒内
- **玩家感受**：每一步都很费力，松手就停——阻力极大
- **通关物理卡**：想动动不了（静摩擦力）

#### 4-3 风洞 ⭐⭐⭐
- **场景**：侧风持续吹，飞飞需要偏航修正
- **任务**：在侧风中到达终点
- **物理参数**：低重力（0.1），有阻力 + 持续侧向风力
- **通关条件**：到达终点且碰撞 ≤ 3
- **三星条件**：碰撞 ≤ 2 / ≤ 1 / 0 次
- **玩家感受**：风把你吹偏，需要持续修正——外力改变运动
- **通关物理卡**：滚滚更轻松（滚动摩擦）

#### 4-4 终端速度 ⭐⭐⭐
- **场景**：高塔下落，需要控制在安全速度内着陆
- **任务**：从塔顶下落，安全着陆
- **物理参数**：强重力（0.3），高阻力（0.05），终端速度约 3.0
- **通关条件**：着陆速度 < 1.5
- **三星条件**：速度 < 1.2 / < 0.8 / < 0.5
- **玩家感受**：下落速度有上限，不会无限加速——终端速度
- **通关物理卡**：空气也来拦你（空气阻力）

#### 4-5 Boss：暴风雪 ⭐⭐⭐⭐
- **场景**：暴风雪中，风向随机变化，有障碍物
- **任务**：在暴风雪中到达终点
- **物理参数**：中重力（0.15），高阻力（0.05），随机风向变化
- **特殊机制**：
  - 风向每 3-5 秒随机改变
  - 风力有 1 秒预警（风向标闪烁）
  - 有冰面区域（低摩擦，飞飞容易打滑）
- **通关条件**：到达终点
- **三星条件**：90秒内 / 60秒内 / 40秒内
- **通关物理卡**（稀有金色）：落到底就不再加速了（收尾速度/终端速度）

---

### 7.5 第五章：引力星 · 详细设计

**星球设定**：太空中有多颗星球，每颗星球都有引力。飞飞需要利用引力绕行或弹射。

#### 5-1 单星环绕 ⭐
- **场景**：一颗行星，飞飞需要绕行一圈
- **任务**：绕行星飞行一圈回到起点
- **物理参数**：无重力，一颗行星的万有引力
- **通关条件**：绕行一圈
- **三星条件**：60秒内 / 40秒内 / 25秒内
- **玩家感受**：被行星拉住，自然形成圆形轨道——引力提供向心力
- **通关物理卡**：万物互相吸引（万有引力定律）

#### 5-2 双星系统 ⭐⭐
- **场景**：两颗行星，引力互相拉扯
- **任务**：从一颗行星旁飞到另一颗行星旁
- **物理参数**：两颗行星的万有引力
- **通关条件**：到达目标区域
- **三星条件**：90秒内 / 60秒内 / 40秒内
- **玩家感受**：被两个方向拉扯——引力的叠加
- **通关物理卡**：越远越没劲（引力与距离的平方反比关系）

#### 5-3 拉格朗日点 ⭐⭐⭐
- **场景**：双星系统中的平衡点，需要悬停
- **任务**：在引力平衡点停留 5 秒
- **物理参数**：两颗行星的万有引力，平衡点引力互相抵消
- **通关条件**：在平衡点区域内停留 5 秒
- **三星条件**：偏离 ≤ 3 / ≤ 2 / ≤ 1 次
- **玩家感受**：两个力互相抵消——力的平衡
- **通关物理卡**：月亮为什么掉不下来（卫星运动/万有引力提供向心力）

#### 5-4 引力弹弓 ⭐⭐⭐
- **场景**：需要借助行星引力加速甩出去
- **任务**：利用引力弹弓到达远处目标

## 11. 物理引擎设计

### 11.1 核心算法

基于帧的 2D 物理模拟：

```
每帧更新（60fps）：
  1. 计算合力（推力 + 重力 + 阻力 + 弹力 + 引力）
  2. F = ma → 加速度
  3. 速度 += 加速度 × dt
  4. 位置 += 速度 × dt
  5. 碰撞检测（边界、障碍物、收集品）
  6. 碰撞响应（反弹、减速、收集）
```

### 11.2 物理参数按章节切换

| 章节 | 重力 | 阻力 | 弹性 | 特殊 |
|------|------|------|------|------|
| 1 惯性星 | 0 | 0 | 0.7 | 无 |
| 2 重力星 | 0.15~0.3 | 0 | 0.5 | 多重力源 |
| 3 弹力星 | 0~0.15 | 0 | 0.9 | 动量守恒 |
| 4 阻力星 | 0~0.15 | 0.02~0.08 | 0.5 | 侧风 |
| 5 引力星 | 0 | 0 | 0.5 | 万有引力 |
| 6 能量星 | 0.15~0.3 | 0.005~0.02 | 0.7 | 能量守恒 |

## 15. 与 funmath 的复用

| 复用项 | 说明 |
|--------|------|
| 技术栈 | 完全一致，Vue3 + Vite + TS |
| 章节结构 | 6章 × (4普通关 + 1Boss) |

| 音效系统 | useSound 可直接复用 |

## 16. 风险与缓解

| 风险 | 缓解措施 |
|------|---------|
| 物理引擎不够精确 | 自写引擎足够简单场景，不做复杂多体碰撞 |
| 触屏操控手感差 | D-Pad 方向键比摇杆更直觉，长按持续施力 |
| Canvas 性能 | 2D 足够，不需要 WebGL；控制场景物体数量 |
| 小朋友不理解物理 | 物理卡用直觉描述，不灌术语；先玩后悟 |
| 关卡难度曲线 | 三星条件拉开差距，一星通关即可 |
| V1 范围过大 | 先做第一章验证核心假设，不贪多 |
